# SpaceTree

Быстрый анализатор занятого места на диске для Windows (в духе WizTree / WinDirStat): дерево папок,
treemap, статистика по типам файлов, поиск и подсказки, что можно безопасно удалить.

![icon](crates/app/assets/icon.png)

## Установка

Скачайте `SpaceTree-Setup.exe` со страницы [Releases](https://github.com/ahsoggg-creator/spacetree/releases/latest)
и запустите. Права администратора не нужны — программа ставится в `%LOCALAPPDATA%\Programs\SpaceTree`.

Установщик добавляет:

- ярлык в меню «Пуск» — SpaceTree находится поиском Windows по слову «spacetree»;
- пункт **«Сканировать в SpaceTree»** в контекстном меню папок, фона папки и дисков
  (в Windows 11 — в «Показать дополнительные параметры», Shift+F10);
- ярлык на рабочем столе (по желанию) и запись в «Приложения и возможности» для удаления.

Есть и переносная версия — просто `SpaceTree.exe`, её можно установить позже из настроек (⚙).

## Возможности

- **Два способа сканирования.** На NTFS с правами администратора SpaceTree читает таблицу MFT напрямую —
  целый диск за секунды (на HDD с 2 млн файлов: ~17 с против многих минут обхода папок). Без прав —
  параллельный обход папок через `GetFileInformationByHandleEx`.
- **Обзор:** дерево с сортировкой по имени, размеру, числу файлов и дате; treemap с анимированным
  приближением, раскраской по типу или по возрасту файлов, подсветкой выбранного расширения.
- **«Можно удалить»:** временные файлы, кэши браузеров и программ, дампы, кэши npm/pip/cargo/Gradle,
  `node_modules`/`target`, старые установщики, возможные дубликаты, корзина — с уровнями
  «безопасно / скорее безопасно / проверьте». Отметьте галочками и удалите в корзину или безвозвратно.
- **Удаление прямо из программы** (Del — в корзину, Shift+Del — безвозвратно) с подтверждением;
  дерево и статистика пересчитываются сразу, без повторного сканирования.
- Поиск по имени (Ctrl+F), крупнейшие файлы, типы файлов, экспорт в CSV, недавние пути,
  навигация стрелками, F5 — пересканировать.
- **Автообновление** из GitHub Releases с проверкой SHA-256 (можно отключить в настройках).

## Сборка

Нужен Rust (stable, edition 2024) и MSVC.

```powershell
cargo build --release            # target\release\SpaceTree.exe и spacetree-cli.exe
cargo test --workspace
powershell -ExecutionPolicy Bypass -File scripts\release.ps1   # артефакты релиза в dist\
```

Структура:

- `crates/core` — модель дерева, сканеры (обход папок, NTFS MFT), статистика, поиск мусора, CSV;
- `crates/app` — GUI на egui, установщик, автообновление, интеграция с Проводником;
- `crates/cli` — `spacetree-cli scan C:\ --top 20 --cleanup --csv out.csv`.

Тот же exe работает как установщик, если называется `SpaceTree-Setup.exe` (или запущен с `--install`),
и как деинсталлятор с `--uninstall`.
